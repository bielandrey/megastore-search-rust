# Sistema de Busca Otimizado para Catálogo de Produtos - MegaStore

## Descrição do Projeto
Este projeto implementa um sistema de busca otimizado para o catálogo de produtos da "MegaStore", uma gigante do varejo de e-commerce. O objetivo principal é solucionar a lentidão e imprecisão das buscas atuais, garantindo que os clientes encontrem produtos de forma rápida e eficiente. O sistema permite indexar o catálogo e realizar buscas por diferentes critérios, como ID e Categoria, garantindo uma melhor experiência do usuário e maior taxa de conversão de vendas.

## Tecnologias Utilizadas
* **Linguagem:** Rust (Edition 2021)
* **Estruturas de Dados Padrão:** `std::collections::HashMap`
* **Ferramentas de Teste:** `cargo test` (Testes unitários nativos do Rust)
